# Installation

## Library

```bash
pip install markowizard
```

That's everything the library needs: optimization (`scipy`), market-data
fetching (`yfinance`), and visualization (`plotly`). No optional extras.

Requires Python 3.10+.

## Web application

The interactive web UI (`backend/` + `frontend/`) is **not part of the PyPI
package** — see [Web Application](web-app.md) for how to run it from a clone
or via Docker.
